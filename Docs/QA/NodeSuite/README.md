# 노드 단계 세팅

노드 트리 그림의 빨간 구역을 단계 1~9로 본다(가운데 반복 노드가 9). 소속은 [zones.json](zones.json), 지도는 [zone-map.svg](zone-map.svg).

## 세팅: qa-nodes-1 ~ qa-nodes-8

N단계 세팅은 **1~N단계 노드를 모두 산 상태**다. 2단계를 샀다면 1단계도 반드시 샀다는 뜻으로 본다. 9단계는 아직 세팅이 없다.

| 세팅 | 보유 노드 | 구매 비용 합계 | 성장 단계 | 이 단계에서 새로 확인할 것 |
| --- | ---: | ---: | :---: | --- |
| qa-nodes-1 | 21 | 757 | 0 | 브레이커 피해·범위·속도·치명타, 소행성 수·크기·질량 |
| qa-nodes-2 | 39 | 14.7K | 0 | Level업 때 시간·소행성 추가 공급, 소행성 파괴 시 시간 추가·재생성 |
| qa-nodes-3 | 70 | 51.8M | 2 | 전기 소행성(연쇄·분열·치명타), 황금 소행성(보상·치명타 보상) |
| qa-nodes-4 | 117 | 113B | 3 | 소행성→행성 변환, 행성 성장 공급, 달, 치명타 혜성, 행성 보너스 피해 |
| qa-nodes-5 | 133 | 1.47T | 3 | 혜성 비, 큰 범위·치명타 확률, 행성 질량·재생성 |
| qa-nodes-6 | 162 | 32T | 3 | 행성→별 변환, 별 성장 공급, 전기 별, 별 보너스 피해 |
| qa-nodes-7 | 212 | 696T | 3 | 레이저 별, 슈퍼노바 별, 전기 별 확장 |
| qa-nodes-8 | 239 | 7.33P | 3 | 슈퍼노바 범위·피해, 레이저 너비·피해 후반, 행성→별 변환 추가 |

- 성장 단계는 추정이다: 구매 비용 합계가 넘은 이정표 목표 잔액 수(Lv10 690K / Lv20 5.6M / Lv30 420M).
- 공통: Gold 0, 시작 Level은 그 성장 단계의 시작, 시드 1, 시간 정상.
- 특수 성질은 확률이다. 한 판에 안 나왔다고 실패로 보지 않는다. 먼저 Test Setup 창 '확정 정보'에서 공급·확률을 본다.

## 실행

1. BlackHole > QA > Validate Node Suite: 8개를 현재 에셋으로 판 조립해 본다(에셋은 바꾸지 않음). 결과는 PlaytestData/node-suite-validation.md.
2. BlackHole > Test Setup에서 분류 'QA/노드 단계'를 고르고 세팅을 불러와 ▶ 플레이.

## 다시 생성·검사

```sh
python Tools/QA/build_node_suite.py      # zones.json 기준으로 세팅·.meta·PlaytestLibrary 목록·zone-map.svg 갱신
dotnet run --project Tests/QA/QA.csproj  # 1~N단계 누적 보유와 구매 경로 연결 확인
```

단계 소속을 바꿀 때는 zones.json을 고치고 생성기를 다시 돌린다. 가격만 바뀌면 세팅은 그대로 유효하다(위 표의 비용·성장 단계만 달라짐).
