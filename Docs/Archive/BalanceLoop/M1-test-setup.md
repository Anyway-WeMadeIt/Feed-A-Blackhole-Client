## 목표

정확히 특정 노드(Rank)를 사고, 정확한 이정표 단계와 블랙홀 Level에 닿은 상태를 자유롭고 편하게 만들어 바로 플레이한다.

전제: 노드 Rank와 이정표 단계만으로 적·Breaker·스탯이 모두 정해진다. 그래서 창은 이 둘과 판 안의 시작 Level만 고치고, 나머지는 게임과 같은 길로 계산해 "확정 정보"로 보여 준다.

## 범위

- 포함: 에디터 창, 확정 정보 계산, 저장·불러오기, 에디터에서 바로 플레이, 플레이 중 다시 적용, 게임에서 가져오기
- 제외: 폰(개발 빌드)에서 세팅 만들기(패널의 시나리오 탭으로 파일을 고르는 것은 된다), 수치 자체 수정(M2·M4)

## 설계

### 창 (메뉴 BlackHole > Test Setup)

| 칸 | 하는 일 |
| --- | --- |
| 노드 트리 | Node Tree 창과 같은 캔버스. 클릭 Rank +1(마지막에서 0), Ctrl+클릭 −1, Delete 0. 초록 = 마지막 Rank, 청록 = 일부, 주황 테두리 = 게임 순서로는 못 삼 |
| 세팅 파일 | 새로·불러오기·저장·다른 이름으로·되돌리기. `Assets/Playtest/Scenarios`의 시나리오 JSON |
| 밸런스 프로필 | 고른 프로필로 미리보고 플레이(플레이 중엔 잠금) |
| 플레이 | ▶ 이 세팅으로 플레이. 플레이 중에는 지금 판에 적용·업그레이드 화면으로·지금 게임에서 가져오기 |
| 세팅 | 이름, 메모, 이정표 단계(예: `1 · Lv10 이정표 지남 → 목표 Lv20`), 블랙홀 Level(단계 시작 ~ 목표−1), Gold, 시드, 시간 고정 |
| 노드 | 산 노드 수·Rank 합·총 비용, 모두 0, 모두 마지막 Rank, 예산으로 싼 것부터 더 사기(게임 규칙), 찾기(−/+/보기) |
| 고른 노드 | Rank별 비용·효과 |
| 확정 정보 | 블랙홀, Breaker, 적 종류별 구성, 바뀐 수치 |

Undo(Ctrl+Z)가 되고, 바뀌면 제목에 `*`가 붙는다. 창에 다시 들어오면 콘텐츠를 다시 불러온다.

### 확정 정보 (`Playtest/TestSetupPreview.cs`)

게임과 같은 길로 판을 조립해서 읽는다. 따로 계산하지 않으므로 창에 보이는 값이 곧 판의 값이다.

1. `ScenarioRunner.TryApply`: 저장을 불러올 때와 같은 검사
2. `NodePurchase.StatsFor` → `GameSessionFactory.Create` → `Begin`
3. `BattleCheats.ReachLevel` → 첫 Step(0.001초)에서 Level업, 성장 공급, 성장 시간

읽는 것:

- 블랙홀: 단계, Level, 목표, 이정표 목표 Gold, 전장 배율, 판 시작 제한 시간, 처치 추가 시간
- Breaker 12개 수치
- 적 종류별: 판 시작 수(성질별), 크기, 질량, 색 비율, 시작 공급 추가, 성장 공급, 승격 수, 1등급 HP·Gold·EXP·속도, 성질 확률과 효과
- 바뀐 수치(기본 → 지금), 총 비용, 게임 순서로 못 사는 노드

### 에디터에서 바로 플레이 (`Playtest/TestSetupLaunch.cs`)

1. 창이 세팅을 SessionState에 맡기고 플레이 모드에 들어간다.
2. 개발 패널이 첫 Update에서 세팅을 꺼내 타이틀을 건너뛰고 판을 시작한다.
3. 남은 세팅은 창의 OnEnable(플레이 전)과 EnteredEditMode에서 지운다.

## Unity 손 확인 순서

1. BlackHole > Test Setup을 연다. 트리가 보이고 확정 정보가 채워지는지 본다.
2. 노드 몇 개를 클릭·Ctrl+클릭한다. 숫자 `r/max`, 색, 확정 정보의 "바뀐 수치"가 바뀌는지 본다. Ctrl+Z로 되돌려 본다.
3. 이정표 단계 1, Level 15로 둔다. 확정 정보의 Level이 `15 (단계 시작 10, 목표 20)`이고 전장 배율이 ×1.68인지 본다.
4. ▶ 이 세팅으로 플레이를 누른다. 타이틀 없이 판이 시작되고, HUD 첫 줄에 `세팅 <이름>`과 Lv 15가 보이는지 본다.
5. 플레이 중 노드를 바꾸고 "지금 판에 적용"을 누른다. 판이 새 세팅으로 다시 시작하는지 본다.
6. 정상 플레이로 몇 판 한 뒤 "지금 게임에서 가져오기"를 누른다. 노드·단계가 창으로 오는지 본다.
7. 저장한 뒤 개발 패널(F1) 시나리오 탭에 같은 이름이 보이는지 본다.
